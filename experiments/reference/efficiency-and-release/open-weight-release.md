## Description

An open-weight release puts the trained parameters on a public host so anyone
can run or fine-tune the model. What the release allows is set by its licence:
Apache 2.0 and MIT allow any use, Llama's community licence adds use limits
and a size threshold, and some releases are for research only. Whether the
training data and code are released too separates an open model from an open-
weight one.

## Why it matters here

The project releases what it builds, so every model it trains needs a licence
and a release form. The entry fixes the vocabulary and the terms of the common
licences so the release decision has a reference to cite.
